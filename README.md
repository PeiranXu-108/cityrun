## 运行

ES 模块需要通过本地服务器打开（不能直接双击 `index.html`）：

```bash
cd ~/game
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

three.js 从 jsDelivr CDN 加载，首次打开需要联网。

## 操作

- 键盘：`← →` / `A D` 换道，`↑` / `W` / 空格 跳，`↓` / `S` 滑铲（空中按下急降），`P` / `Esc` 暂停
- 手机：左右滑换道，上滑跳，下滑滑铲

迎面撞上障碍会结束；侧面擦碰会被保安和狗追上，短时间内再擦碰一次就会被抓。坡道可以跑上列车顶。

## 玩法系统

- 道具：磁铁、喷气背包（空中金币）、弹跳鞋（可直接跳上车顶，带空翻）、双倍分数、护盾
- 迎面开来的列车会鸣笛，从相邻轨道擦身而过有奖励
- 任务系统：每完成 3 个任务基础倍率 +1，奖励金币
