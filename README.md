## 运行

ES 模块需要通过本地服务器打开（不能直接双击 `index.html`）：

```bash
cd ~/game
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

three.js 从 jsDelivr CDN 加载，首次打开需要联网。

## 操作

- 键盘：`← →` / `A D` 换道，`↑` / `W` / 空格 跳，`↓` / `S` 滑铲（空中按下急降），`P` / `Esc` 暂停
- 手机：左右滑换道，上滑跳，下滑滑铲

迎面撞上障碍会结束；侧面擦碰会被保安和狗追上，短时间内再擦碰一次就会被抓。坡道可以跑上列车顶。

## 玩法系统

- 道具：磁铁、喷气背包（空中金币）、弹跳鞋（可直接跳上车顶，带空翻）、双倍分数、护盾
- 迎面开来的列车会鸣笛，从相邻轨道擦身而过有奖励
- 任务系统：每完成 3 个任务基础倍率 +1，奖励金币
- 角色：阿杰（默认）、米娅、零号机器人、熊猫滚滚、招财猫福猫、兔儿爷（金盔红袍、背插靠旗）、自由女神（举着火炬跑）、考拉（抱着一片桉树叶）、皇家卫兵（红上衣白腰带、高高的黑熊皮帽，待机时立正站岗）、纳西阿妹（蓝帽、紫红坎肩和黑围腰，胸前交叉系着白色背带，背上的羊皮披肩绣着日月和七颗星，「披星戴月」）、巴黎女孩（红色贝雷帽、波波头、海魂衫和红色小方巾，手里攥着一根法棍）、醒狮（红金狮头：额上的镜子、大眼、白狮毛和独角，身后披着狮被，跑起来狮口一张一合）、电音三太子（大大的娃娃头戴着墨镜、含着奶嘴，头顶两个发髻，金甲红肚兜，斜挎乾坤圈，飘着混天绫，脚踩一对呼呼转的风火轮，待机时跳起电音舞），用金币解锁
- 东京的高栏是铁路道口（踏切），红灯交替闪烁，靠近时会响道口铃；开局和进入东京时会播放车站发车旋律
- 北京开局和进入北京时会响一段京剧锣鼓「四击头」；纽约是地铁关门的两声提示音；悉尼是一声笑翠鸟的「笑声」；伦敦是大本钟的威斯敏斯特报时钟声，最后敲响一记整点钟；丽江是一串叮咚作响的风铃，夹着马帮的铃铛声；巴黎是手风琴呼出的一个和弦，接着一串叮叮的闪光像铁塔的灯一样从高处洒下来；香港是叮叮车的两声铃，一串扬琴从低到高扫上去，再响两声铃（迎面开来的叮叮车也会摇铃）；台北是垃圾车喇叭里有点失真的《给爱丽丝》（迎面开来的垃圾车也放这首）
- 每个城市一首程序生成的配乐（Web Audio 合成，无音频文件）；纽约是爵士嘻哈：boom-bap 鼓组、行走的低音提琴、Rhodes 电钢琴反拍和弦、A 小调蓝调的次中音萨克斯和黑胶底噪；东京是日式小调 + 现代电子：平调子音阶的筝、尺八、三味线和太鼓，叠加 808 低音、拍手和 trap 连击踩镲，16 小节一轮（前奏 → 铺垫 → drop → 尺八主旋律）；北京是京剧 + 嘻哈：板鼓、大锣、小锣、铙钹的锣鼓经，五声音阶的京胡旋律、琵琶轮指和笛子，叠加 boom-bap 鼓组和 808，每轮以「四击头」收尾；悉尼是澳洲原住民元素 + 热带浩室（tropical house）：迪吉里杜管的长呼吸与律动、拍棍节奏，叠加四踩底鼓、拍手、沙锤和 sub 低音，A 大调 Amaj7–F#m7–Dmaj7–E6 和弦上的反拍马林巴拨弦、drop 段的泵感和弦、五声音阶的锯齿波主旋律，每轮第 16 小节留出 breakdown；伦敦是圣诞颂歌 + 英国车库舞曲（UK garage）：每轮开头教堂钟敲出威斯敏斯特整点报时（四段变奏），合唱团「啊」声铺底，鼓点进来时敲响整点大钟，随后是 2-step 切分鼓组、滚动的 sub 低音、风琴和弦切片、雪橇铃和钢片琴琶音，G 和声小调 Gm7–E♭maj7–Cm7–D7 上的铜管乐队颂歌旋律，最后一段由钢片琴高八度接过旋律、合唱团再次进入；丽江是纳西民谣 + 世界音乐律动（104 BPM，带一点摇摆）：口弦在主音上弹拨、马帮铃铛、吉他分解和弦和持续低音开场，随后进入非洲手鼓律动、轻底鼓、拍手、沙锤、吉他扫弦和 sub 低音，A 小调 Am–F–C–G 和弦上是五声音阶的葫芦丝旋律，最后一段由竹笛（高八度）和葫芦丝轮流吹奏，每轮第 16 小节以手鼓滚奏和铃铛收尾；巴黎是手风琴缪塞特 + 吉普赛爵士 + 法式浩室（French house，124 BPM）：每轮开头是咖啡馆里的手风琴（三组簧片互相拍频的 musette 音色），配吉普赛吉他「la pompe」的切音和低音提琴，D 和声小调 Dm6–Gm6–B♭7–A7 上的手风琴旋律；随后进入四踩底鼓、拍手和反拍开镲，滤波器渐渐打开、随底鼓起伏的和弦，八度跳跃的放克贝斯；drop 段手风琴重回旋律、钢片琴点缀闪光，最后一段由小提琴接过旋律，每轮第 16 小节以手风琴的半音阶爬升收尾；香港是八十年代粤语流行 + 城市流行（city pop，104 BPM）：每轮开头是扬琴在电钢琴和铺底上波光粼粼的分解和弦，随后进入门限军鼓、十六分音符踩镲、八度跳跃的拨弦贝斯和反拍 Rhodes，Fmaj7–E7–Am7–Gm7 C7 上由二胡唱出旋律，副歌由方波合成器带领、合成铜管应答，最后一段扬琴高八度接过旋律，每轮第 16 小节以木鱼滚奏和一记小锣收尾；台北是台式电音（128 BPM，庙会里电音三太子跳舞的那种）：每轮开头唢呐在北管通鼓和铙钹上吹一段开场，一串鞭炮炸进 drop——四拍底鼓、滚动的反拍贝斯和拍手，唢呐吹 D 小调五声音阶的主旋律（Dm–B♭–C–Am）；中段让北管锣鼓独奏，最后一段加上 trance 超级锯齿波和高八度的合成器，再一串鞭炮接回开头
- 画质切换：高（泛光 + 后期）/ 低；帧率过低时自动降级
- 进度保存在浏览器 localStorage
